AI-Based PPE Compliance Detection
  • Developed and upgraded industrial PPE detection pipelines, migrating YOLOv3 → YOLOv8 for improved accuracy and inference speed.
  • Created and annotated a dataset of 15,000+ images across 6 PPE classes for robust model retraining.
  • Designed real-time alert mechanisms on PPE violations; deployed in live industrial environments.
Stack: Python, YOLOv8, YOLOv3, OpenCV, PyTorch
The Plan
Manual PPE compliance checks on a factory floor don't scale across shifts and cameras. The goal was a system that watches live NVR camera feeds continuously, flags missing helmets/vests/shoes/glasses/masks in real time, and automatically saves evidence video of each violation for review — running unattended, 24/7, across multiple camera channels.
Architecture

Shown at a high level — this system was built for a Xiphos client and was never open-sourced, so infrastructure specifics (camera/network details, credentials) are intentionally omitted.
Implementation
  • Threaded frame capture decouples network/camera latency from the detection loop, so the system stays responsive even on unreliable RTSP connections
  • YOLOv8 inference runs on a resized 640×640 frame; detections below 80% confidence are discarded to minimize false alarms in a safety-critical setting
  • Full-duration frame buffering (e.g. 250 frames for a 10s clip at 25fps) captures before/during/after context for each incident rather than saving on first detection
  • Two-stage atomic file writes (temp folder → final folder) ensure downstream systems never read a partially-written video
  • Three independent log streams — detection log, real-time announcement log, and error log — plus automatic crash recovery that restarts the main loop on any uncaught exception
  • Multi-camera deployment by running one instance per NVR channel

IoT-Based Wildlife Monitoring & Alert System (R&D)
  • IoT-integrated AI system using Raspberry Pi and PIR sensors for motion-triggered elephant classification.
  • Real-time alerting with false-alarm filtering for field deployment.
Stack: Python, Raspberry Pi, PIR Sensors, OpenCV
The Plan
Human-elephant conflict causes both loss of life and crop damage. The idea was a low-cost field sensor that detects nearby movement, captures an image, and uses AI to tell whether it's an elephant or a human — routing only relevant detections to a monitoring dashboard, without needing constant video streaming from remote field locations.

Implementation
  • Raspberry Pi with an ultrasonic sensor (trig/echo on GPIO 23/24) detects motion within ~200cm and triggers a USB camera capture
  • Captured images are uploaded to a local MySQL database table for the processing machine to pick up
  • A GPU-enabled Windows machine downloads new images and runs an AI/ML model (Ultralytics-based) to classify human vs elephant
  • Relevant detections are moved to a shared folder consumed by a separate dashboard (built by the Java developer team) for monitoring and visualization
R&D stage — this system was prototyped and validated in development but was not field-tested in a real deployment.
